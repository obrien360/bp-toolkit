How PDF Window Measurement Completion Works

1. Ground Truth Learning

The tool scans your elevation PDF for representative manual measurements (Bluebeam Area markups / Polygon annotations) and matches them to nearby window type labels (such as W01, W02, W05). It learns:

  • Representative window width, height, and area string.
  • Initial label-to-window relative spatial offset.
  • Bluebeam scale calibration (/Measure dictionary, e.g. 1/4" = 1'-0").
  • Stroke color, fill color, and exact 30% fill opacity (/FillOpacity .3, /ca .3).

2. Drawing-Edge Snapping (Computer Vision)

Rather than relying solely on the text label coordinate, the engine renders an edge energy map that filters out light facade hatching while detecting crisp architectural window outlines. It evaluates candidate positions on a sub-point grid and snaps the rectangle to true vector frame lines.

3. Double-Counting & Overlap Protection

Before adding any new annotation, the tool performs spatial collision checks against existing manual markups and previously placed windows. Overlapping positions are discarded to ensure total window counts and areas remain 100% accurate.

4. Native Bluebeam Revu Compatibility

Generated annotations are written with native PDF /PolygonDimension, /Measure, /Vertices, and /RC rich text structures. When opened in Bluebeam Revu, they are fully editable, selectable, and support recalculation and area takeoff reports.
