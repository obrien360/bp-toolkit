Conversion Rules & Architecture

Simplification Rules Applied:

  1. Shared Wall Single-Line Deduplication: When two zones share a wall, only one single line is drawn instead of two duplicate overlapping lines.
  2. Orthogonal Snapping (±5°): Any wall segment within ±5.0° (editable) of horizontal or vertical is snapped to strict 0° or 90°.
  3. Zero Open Ends: All walls intersect cleanly to form closed planar loops, preventing "open polyloop" errors in building energy models.
  4. Layer Separation: Each level is grouped into distinct AutoCAD layers (LEVEL_1, LEVEL_1_POLYLOOPS, LEVEL_1_TEXT).
  5. Sequential Overlay Snapping: The selected base level is converted first. Each following level snaps to the coordinate grid of the level converted immediately before it.
  6. Horizontal Spread Export: Levels can be exported horizontally spaced by 120% of maximum building width with floor labels.
